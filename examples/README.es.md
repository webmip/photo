# 🖼️ Examples Directory

Esta carpeta contiene imágenes de ejemplo generadas usando los prompts del repositorio.

## 📂 Estructura

```
examples/
├── nanobanana/        # Ejemplos generados con NanoBanana
├── gpt-5/             # Ejemplos generados con GPT-5
├── midjourney/        # Ejemplos generados con Midjourney
├── dalle/             # Ejemplos generados con DALL-E
└── stable-diffusion/  # Ejemplos generados con Stable Diffusion
```

## 📝 Convenciones de Nombres

Los archivos de ejemplo deben seguir este formato:

```
[categoria]-[descripcion-breve].[extension]
```

**Ejemplos:**
- `portrait-fire-water-duality.jpg`
- `landscape-cyberpunk-street.jpg`
- `artistic-abstract-geometry.png`

## 🎨 Especificaciones de Imágenes

### Formato
- **Preferido**: JPG para fotografías, PNG para gráficos
- **Tamaño máximo**: 2MB por imagen
- **Resolución recomendada**: 1024x1024 o similar

### Calidad
- Imágenes de alta calidad que demuestren el prompt
- Sin marcas de agua (a menos que sean del modelo)
- Resultados reales, no editados posteriormente

## 📸 Añadir Ejemplos

Al contribuir con un nuevo prompt:

1. **Genera** la imagen usando tu prompt
2. **Guarda** en la carpeta del modelo correspondiente
3. **Nombra** según las convenciones
4. **Referencia** en tu archivo de prompt

**Ejemplo en tu prompt:**
```markdown
## 🖼️ Ejemplos Visuales

![Fire Water Portrait](../../examples/nanobanana/portrait-fire-water-duality.jpg)
*Descripción del resultado*
```

## ⚠️ Consideraciones

- **Derechos**: Solo sube imágenes que hayas generado tú
- **Contenido**: Mantén el contenido apropiado y profesional
- **Relevancia**: La imagen debe corresponder exactamente al prompt

## 🔍 Explorar Ejemplos

Navega por las carpetas para ver ejemplos de cada modelo y categoría. Cada imagen debe tener su prompt correspondiente en la carpeta `/prompts`.
