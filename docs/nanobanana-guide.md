## 📖 Introduction

NanoBanana is an AI model specialized in generating images with **extreme photorealism**. This guide will help you make the most of its capabilities.

## 🎯 Key Features

- **Extreme photorealism**: Ultra-realistic details and textures
- **Advanced lighting**: Exceptional handling of light and shadows
- **Precise anatomy**: Realistic representation of human figures
- **Special effects**: Fire, water, smoke with great detail

## 💡 Best Practices

### Prompt Structure

```
[Style/Quality] + [Main Subject] + [Action/Pose] + [Environment] + [Lighting] + [Technical Details]
```

**Example:**
```
Epic cinematic hyper-realistic portrait of a warrior, standing confidently, 
dramatic lighting with rim light, volumetric fog, 8k ultra detailed, 
professional photography
```

### Key Tips

1. **Specify quality at the beginning**
   - `hyper-realistic`, `photorealistic`, `8k ultra detailed`

2. **Describe the lighting**
   - `dramatic lighting`, `golden hour`, `studio lighting`

3. **Add technical details**
   - `shallow depth of field`, `bokeh`, `professional photography`

4. **Use cinematic references**
   - `cinematic`, `epic`, `movie still`

## 🚫 Recommended Negative Prompts

```
blurry, low quality, distorted, deformed, ugly, bad anatomy, 
bad proportions, extra limbs, cloned face, disfigured, 
gross proportions, malformed limbs, missing arms, missing legs, 
extra arms, extra legs, fused fingers, too many fingers, 
long neck, cartoon, anime, painting, drawing, sketch
```

## ⚙️ Typical Parameters

| Parameter | Recommended Value | Notes |
|-----------|-------------------|-------|
| Steps | 30-50 | More steps = more detail |
| CFG Scale | 7-12 | 7-9 for natural, 10-12 for strict adherence |
| Resolution | 1024x1024 or higher | Higher resolution = more detail |
| Sampler | DPM++ 2M Karras | Good quality/speed balance |
