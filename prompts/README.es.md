## 📝 Cómo Usar

1. **Navega** a la carpeta del modelo que usas
2. **Explora** las categorías disponibles
3. **Abre** el archivo `.md` del prompt que te interese
4. **Copia** el prompt y parámetros
5. **Genera** tu imagen

## 🎨 Categorías

### Portrait
Prompts para retratos, fotografía de personas, expresiones faciales, y composiciones centradas en sujetos humanos.

### Landscape
Prompts para paisajes, escenas naturales, arquitectura, y composiciones de entornos.

### Artistic
Prompts para arte conceptual, composiciones creativas, y experimentación visual.

### Fashion
Prompts específicos para fotografía de moda, editorial, y estilismo (disponible en algunos modelos).
