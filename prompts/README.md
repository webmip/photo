## 📝 How to Use

1. **Navigate** to the folder of the model you use
2. **Explore** available categories
3. **Open** the `.md` file of the prompt you're interested in
4. **Copy** the prompt and parameters
5. **Generate** your image

## 🎨 Categories

### Portrait
Prompts for portraits, people photography, facial expressions, and human-centered compositions.

### Landscape
Prompts for landscapes, natural scenes, architecture, and environment compositions.

### Artistic
Prompts for conceptual art, creative compositions, and visual experimentation.

### Fashion
Specific prompts for fashion photography, editorial, and styling (available in some models).
